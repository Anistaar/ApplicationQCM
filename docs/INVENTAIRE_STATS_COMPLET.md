## 🗂️ Structure des 4 Chapitres

### **📐 Chapitre 1 : Notions statistiques et collecte des données**
**Objectif** : Fondamentaux de la statistique descriptive, vocabulaire de base, collecte des données

**Sous-chapitres** :
1. **Introduction à la statistique**
   - Définition (techniques quantitatives pour analyser phénomènes)
   - 3 fonctions : Décrire, Expliquer, Prédire
   - Statistique descriptive vs inférentielle vs inférence causale

2. **Pièges et biais statistiques**
   - Biais de sélection (motivation, endogamie, technologique)
   - Biais du survivant (exemple avions WWII)
   - Corrélation ≠ Causalité
   - Erreurs de visualisation (échelles, pourcentages >100%)

3. **Vocabulaire de base**
   - **Population (Ω)** : Ensemble unités statistiques
   - **Échantillon (O ⊆ Ω)** : Sous-ensemble observé
   - **Individu (ω)** : Élément de la population
   - **Variable (X)** : Caractère étudié
   - **Modalité** : Valeurs possibles de X
   - **Effectif (n)** : Nombre d'individus

4. **Types de variables**
   - **Qualitatives** : Nominale (CSP, couleurs) vs Ordinale (satisfaction, taille vêtements)
   - **Quantitatives** : Discrète (nombre enfants) vs Continue (taille en cm, salaire)

5. **Effectifs et fréquences**
   - Effectif partiel (n_i), effectif cumulé (croissant/décroissant)
   - Fréquence simple (f_i = n_i/N), fréquence cumulée (FCC, FCD)

6. **Regroupement en classes**
   - Amplitude (A = b-a), Centre (C = (a+b)/2)
   - Règles : Empirique (2^k ≥ N), Sturge (k ~ 1+3,3×log(N)), Yule (k ~ 2,5×N^(1/4))

7. **Opérateurs mathématiques**
   - Somme (Σ) : Propriétés, développements
   - Produit (∏) : Propriétés

### **📊 Chapitre 2 : Présentation graphique des données**
**Objectif** : Visualiser et communiquer efficacement les données statistiques

**Sous-chapitres** :
1. **Principes généraux d'un graphique**
   - Objectifs : Synthèse visuelle, lisibilité, comparaison
   - Règles : Clarté, esthétique, adaptation type variable, minimalisme

2. **Éléments obligatoires**
   - Titre énonciatif
   - Axes clairement explicités (unités)
   - Note de lecture (exemple interprétation)
   - Source des données
   - Légende (si besoin)
   - Commentaire accompagnement

3. **Erreurs à éviter**
   - Échelles déformantes (axes tronqués)
   - Pourcentages >100%
   - Comparaisons non comparables
   - Surcharge d'informations
   - Manipulation données

4. **Graphiques pour variables qualitatives**
   - **Diagramme en barres** : Barres verticales/horizontales
   - **Diagramme en bâtons** : Pour effectifs discrets
   - **Diagramme circulaire (camembert)** : Proportions (max 6-7 modalités)
   - **Diagramme en secteurs** : Variante camembert

5. **Graphiques pour variables quantitatives**
   - **Histogramme** : Classes continues, aire proportionnelle effectif
   - **Polygone des effectifs** : Courbe continue
   - **Courbe cumulative** : FCC ou FCD (ogive)
   - **Diagramme en boîte (boxplot)** : Médiane, quartiles, outliers

### **📈 Chapitre 3 : Mesures de tendance centrale**
**Objectif** : Résumer une série statistique par une valeur centrale représentative

**Sous-chapitres** :
1. **Le Mode (Mo)**
   - Modalité la plus fréquente
   - Variables qualitatives/quantitatives discrètes : Effectif maximal
   - Variables continues : Classe modale, interpolation (formule Czuber)
   - Peut être multimodal (plusieurs modes)

2. **La Médiane (Me)**
   - Valeur centrale : 50% observations ≤ Me, 50% ≥ Me
   - Série ordonnée : Position n/2 (si n pair : moyenne des 2 valeurs centrales)
   - **Robuste aux valeurs extrêmes** (outliers)
   - Données groupées : Interpolation linéaire dans classe médiane

3. **Généralisation : Quantiles**
   - **Quartiles (Q1, Q2=Me, Q3)** : Divisent en 4 parts égales
   - **Déciles (D1, D2, ..., D9)** : Divisent en 10 parts égales
   - **Percentiles (P1, P2, ..., P99)** : Divisent en 100 parts égales
   - Utilisation : Distribution revenus (D9/D1), scores standardisés

4. **Moyenne Arithmétique (x̄)**
   - Formule : x̄ = (1/n) Σx_i = Σx_i / n
   - **Moyenne pondérée** : x̄ = Σ(w_i × x_i) / Σw_i
   - Propriétés : Σ(x_i - x̄) = 0, sensible aux outliers
   - Centre de gravité de la distribution

5. **Moyenne Géométrique (G)**
   - Formule : G = (Πx_i)^(1/n) = ⁿ√(x₁ × x₂ × ... × xₙ)
   - **Usage** : Taux de croissance successifs, indices économiques
   - Exemple : Croissance +20% puis +25% → G ≈ 22,47%
   - Non définie si x_i ≤ 0

6. **Moyenne Harmonique (H)**
   - Formule : H = n / Σ(1/x_i)
   - **Usage** : Moyennes de vitesses (même distance), prix unitaires
   - Exemple : Aller 60 km/h, retour 40 km/h → H = 48 km/h
   - H ≤ G ≤ x̄ (inégalité des moyennes)

7. **Comparaison des indicateurs**
   - **Mode** : Simple, robuste, pas unique
   - **Médiane** : Robuste, position centrale, peu sensible outliers
   - **Moyenne arithmétique** : Sensible outliers, calculs algébriques
   - **Géométrique** : Croissances multipliées
   - **Harmonique** : Ratios (vitesses, prix)

### **📏 Chapitre 4 : Caractéristiques de dispersion**
**Objectif** : Mesurer l'étalement des données autour d'une valeur centrale

**Sous-chapitres** :
1. **Dispersion par rapport à la médiane**
   - **Étendue (Range)** : E = X_max - X_min
     - Simple, sensible outliers
   - **Écart interquartile (IQR)** : IQR = Q3 - Q1
     - Robuste, contient 50% central
   - **Écart interdécile** : D9 - D1
     - Mesure inégalités (revenus)

2. **Dispersion autour de la moyenne**
   - **Variance (V ou σ²)**
     - Formule : V = (1/n) Σ(x_i - x̄)²
     - Variance corrigée : s² = (1/(n-1)) Σ(x_i - x̄)² (échantillon)
     - Unité : Carré de l'unité de X
   
   - **Écart-type (σ ou s)**
     - Formule : σ = √V
     - Même unité que X
     - Mesure dispersion absolue
   
   - **Coefficient de variation (CV)**
     - Formule : CV = (σ / x̄) × 100
     - **Sans unité** (dispersion relative)
     - Comparaison séries différentes unités

3. **Propriétés des mesures de dispersion**
   - Translation (x_i + c) : σ inchangé, CV change
   - Homothétie (a×x_i) : σ multiplié par |a|, CV inchangé
   - Variance = Moyenne des carrés - Carré de la moyenne : V = E[X²] - (E[X])²

4. **Interprétation**
   - **Faible dispersion** : Données concentrées autour moyenne
   - **Forte dispersion** : Données étalées, moyenne peu représentative
   - Règle empirique (loi normale) : ~68% dans [x̄-σ, x̄+σ], ~95% dans [x̄-2σ, x̄+2σ]

5. **Boîte à moustaches (Boxplot)**
   - **Boîte** : Q1, Me, Q3
   - **Moustaches** : Min/Max (ou 1,5×IQR)
   - **Outliers** : Points au-delà des moustaches
   - Visualisation rapide : Centre, dispersion, asymétrie, valeurs extrêmes

## 🏷️ Formules Statistiques Clés

### **Chapitre 1 : Bases**
```
Effectif cumulé : n = Σn_i
Fréquence simple : f_i = n_i / N
Fréquence cumulée croissante : FCC_i = Σ(j=1 à i) f_j
Amplitude classe : A = b - a
Centre classe : C = (a + b) / 2
Nombre classes (Sturge) : k ≈ 1 + 3,3 × log₁₀(N)
```

### **Chapitre 3 : Tendance Centrale**
```
Médiane (série ordonnée) : 
  - Si n impair : Me = x_{(n+1)/2}
  - Si n pair : Me = (x_{n/2} + x_{(n/2)+1}) / 2

Moyenne arithmétique : x̄ = (1/n) Σx_i
Moyenne pondérée : x̄ = Σ(w_i × x_i) / Σw_i
Moyenne géométrique : G = (Πx_i)^(1/n)
Moyenne harmonique : H = n / Σ(1/x_i)

Inégalité des moyennes (x_i > 0) : H ≤ G ≤ x̄
```

### **Chapitre 4 : Dispersion**
```
Étendue : E = X_max - X_min
Écart interquartile : IQR = Q3 - Q1

Variance : V = (1/n) Σ(x_i - x̄)²
         ou V = (1/n) Σx_i² - x̄²
         ou V = E[X²] - (E[X])²

Écart-type : σ = √V

Coefficient de variation : CV = (σ / x̄) × 100 (en %)

Variance pondérée : V = Σ(w_i × (x_i - x̄)²) / Σw_i
```

### **Transformations**
```
Si Y = aX + b alors :
  - ȳ = ax̄ + b
  - σ_Y = |a| × σ_X
  - V_Y = a² × V_X
  - CV_Y = (|a| × σ_X) / (ax̄ + b) × 100
```

## 📐 Indicateurs Économiques & Statistiques

### **IPC (Indice des Prix à la Consommation)**
- **Formule Laspeyres** : IPC_t = [Σ(p_t × q_0) / Σ(p_0 × q_0)] × 100
- **Pondérations** : Budget moyen ménages, MAJ annuelles
- **COICOP** : 12 postes (alimentation, logement, transport, santé, etc.)
- **Biais** :
  - Substitution (changement habitudes non capté)
  - Effet qualité (amélioration produits)
  - Shrinkflation (↓ quantité à prix =)
  - Ajustements hédoniques (décomposition prix selon attributs)

### **Indices Économiques**
- **Indice simple** : I_t = (X_t / X_0) × 100
- **Taux de variation** : τ = [(X_t - X_{t-1}) / X_{t-1}] × 100
- **Indice chaîné** : I_t = I_{t-1} × (X_t / X_{t-1})

### **Déciles & Inégalités (Revenus)**
- **D1** : 10% population gagne moins
- **D9** : 90% population gagne moins
- **Rapport D9/D1** : Mesure inégalités (France ~3,5)
- **Courbe de Lorenz** : Cumul % revenus vs cumul % population
- **Coefficient de Gini** : Aire sous courbe Lorenz (0 = égalité parfaite, 1 = inégalité max)

## 💡 Observations

### **Points Forts**
1. **Structure pédagogique progressive** : 4 chapitres logiques (bases → visualisation → centralité → dispersion)
2. **Gradation difficulté** : Chaque chapitre décliné en 3 niveaux (facile, moyen, difficile) + examen type
3. **Couverture complète** : Tous les indicateurs statistiques descriptifs essentiels (mode, médiane, moyennes, variance, écart-type, quartiles)
4. **Formules clairement présentées** : Notations mathématiques rigoureuses, propriétés algébriques
5. **Applications économiques** : IPC, indices prix, inégalités revenus (déciles)
6. **Exemples concrets** : Vitesses, croissances, salaires, notes, satisfaction

### **Spécificités de la Matière**
- **Mathématiques appliquées** : Opérateurs Σ et ∏, propriétés algébriques, développements
- **Dualité calcul/interprétation** : Formules + sens économique/statistique
- **Vigilance biais** : Sensibilisation critique (corrélation ≠ causalité, échelles trompeuses)
- **Visualisation cruciale** : 1 chapitre entier (20% contenu) sur graphiques
- **Robustesse vs précision** : Médiane (robuste outliers) vs Moyenne (sensible, calculs)

### **Lacunes Potentielles**
1. **Pas de covariance/régression** : Analyse bivariée absente (corrélation, droite régression)
2. **Pas de loi de probabilité** : Distribution normale, loi binomiale → Limite descriptive
3. **Peu d'applications spécifiques économie** :
   - Courbe de Lorenz (inégalités) : Évoquée mais pas détaillée
   - Coefficient Gini : Absent
   - Élasticités : Absent
4. **Tests d'hypothèse absents** : Statistique inférentielle (IC, tests) non couverte (hors scope cours)
5. **Peu d'exemples actuels** : Inflation 2022-2023, PIB COVID, données récentes

#### **1. Enrichir applications économiques**
- **Chapitre 3** : Ajouter calculs déciles revenus France (D1/D9/D5), courbe Lorenz, Gini

- **Régression linéaire simple** : Y = aX + b (MCO)
- **Applications** : Relation revenu/consommation, prix/demande

## 📚 Concepts Avancés à Maîtriser

### **Inégalité des Moyennes (H ≤ G ≤ x̄)**
Pour x_i > 0 strictement positifs :
- **H** (Harmonique) ≤ **G** (Géométrique) ≤ **x̄** (Arithmétique)
- Égalité ssi tous x_i égaux
- Démonstration : Inégalité arithmético-géométrique (Cauchy)

### **Formule König (Variance)**
```
V = E[X²] - (E[X])²
  = (1/n) Σx_i² - x̄²
```
Utile pour calculs rapides, évite de calculer (x_i - x̄)² pour chaque i

### **Règle Empirique (68-95-99,7)**
Pour distribution approximativement normale :
- ~68% données dans [x̄ - σ, x̄ + σ]
- ~95% données dans [x̄ - 2σ, x̄ + 2σ]
- ~99,7% données dans [x̄ - 3σ, x̄ + 3σ]

### **Médiane Groupée (Interpolation Linéaire)**
```
Me = L + [(n/2 - F_préc) / f_m] × h

Où :
  L = Borne inférieure classe médiane
  n = Effectif total
  F_préc = Effectif cumulé avant classe médiane
  f_m = Effectif classe médiane
  h = Amplitude classe médiane
```

### **Mode Groupé (Formule Czuber)**
```
Mo = L + [Δ₁ / (Δ₁ + Δ₂)] × h

Où :
  L = Borne inférieure classe modale
  Δ₁ = f_m - f_{m-1} (différence effectif classe modale et précédente)
  Δ₂ = f_m - f_{m+1} (différence effectif classe modale et suivante)
  h = Amplitude classe modale
```

### **Théorème Changement Origine/Échelle**
Si Y = aX + b alors :
- E[Y] = a×E[X] + b = a×x̄ + b
- V[Y] = a² × V[X]
- σ[Y] = |a| × σ[X]
- CV[Y] = (|a|×σ[X]) / (a×x̄ + b) × 100
