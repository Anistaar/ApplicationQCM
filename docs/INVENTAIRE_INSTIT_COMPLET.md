## 🏷️ Thèmes/Concepts Principaux

### **Théorie Institutionnelle**
- Institution = règles du jeu (North) ≠ Organisation = joueurs
- Institutions formelles (lois, constitutions) vs informelles (normes, coutumes)
- Path dependence (dépendance au sentier)
- Efficacité adaptative

### **Organisations Internationales**
- **FMI** : Prêteur de dernier ressort, conditionnalité, surveillance SMI
- **OMC** : Commerce multilatéral, ORD (règlement différends), ADPIC (propriété intellectuelle)
- **Banque Mondiale** : Développement long terme, lutte pauvreté, gouvernance

### **Asymétries d'Information**
- **Sélection adverse** (Akerlof 1970) : Information cachée AVANT transaction → "lemons" chassent produits qualité
- **Aléa moral** : Information cachée APRÈS transaction → comportement plus risqué (assurance)
- **Signaux** (Spence) : Diplôme comme signal productivité, coût corrélé qualité

### **Coûts de Transaction & Firmes**
- **Coase (1937)** : Firme existe pour réduire coûts de transaction du marché
- **Williamson (1975)** : Spécificité actifs, incertitude, opportunisme, rationalité limitée
- Arbitrage marché / hiérarchie / hybride

### **Droits de Propriété & Biens Communs**
- **Tragédie des communs** (Hardin 1968) : Surexploitation ressources (accès libre + rivalité)
- **Solutions** : Privatisation, gestion collective (Ostrom), régulation publique
- **Théorème de Coase** : Si droits propriété définis et coûts transaction nuls → allocation optimale

### **Gouvernance**
- **Bonne gouvernance (BM)** : Efficacité, responsabilisation (accountability), transparence, participation
- **Gouvernance moderne** : Réseaux d'acteurs, pouvoirs multicentrés, négociation
- **Rodrik (2005)** : 4 familles institutions (création, régulation, stabilisation, légitimation marché)

### **Statistiques & IPC**
- **IPC** : Indice Laspeyres chaîné, pondérations MAJ annuelles, ajustements hédoniques
- **Biais** : Substitution, effet qualité, shrinkflation (réduction quantité à prix constant)
- **INSEE** : Collecte, production, diffusion statistiques publiques

### **Normes Comptables**
- **IFRS** : Orientation investisseur, juste valeur, volatilité accrue
- **Continental** : Prudence, coût historique, protection créanciers
- **Principes français** : Image fidèle, régularité, sincérité, continuité exploitation

## 📐 Formules/Indicateurs Clés

### **FMI**
- **DTS** (Droits de Tirage Spéciaux, 1969) : Panier devises (Dollar, Euro, Yuan, Yen, Livre)
- **Quote-part** : Souscription capital → droit vote + montant empruntable
- **Bretton Woods** : 35$ l'once d'or (jusqu'en 1971)
- **Stock or FMI** : 2 814 tonnes (3e mondial)

### **OMC**
- **Rounds GATT** : 8 rounds (1-6 tarifs douaniers, 7-Tokyo mesures non tarifaires, 8-Uruguay création OMC)
- **Accord Marrakech** (1994) : ~20 000 pages, 29 accords
- **ORD** : 606 différends depuis 1995, >350 décisions
  - 488 cas GATT (droits douane)
  - 137 cas anti-dumping
  - 130 cas subventions

### **Gouvernance**
- **IPC France** : 25e/180 pays
- **Doing Business** : Facilité faire affaires
- **Worldwide Governance Indicators** : Rule of Law, Government Effectiveness

### **IPC (Indice Prix Consommation)**
- **Formule Laspeyres chaîné** : IPC_t = Σ(p_t × q_0) / Σ(p_0 × q_0) × 100
- **Pondérations** : MAJ annuelles selon budget moyen ménages
- **COICOP** : Classification dépenses consommation (12 postes)

### **IFRS vs Continental**
- **Juste valeur** : Réévaluation à chaque clôture, volatilité ↑, réactivité marchés
- **Coût historique** : Valeur acquisition, amortissement systématique, stabilité

## 💡 Observations

### **Points Forts**
1. **Couverture exhaustive** des 3 organisations internationales majeures (FMI, OMC, BM)
2. **Équilibre théorie/pratique** : Fondements théoriques solides (North, Coase, Williamson) + applications concrètes
3. **Fichiers TRAIN ciblés** : Excellente approche pédagogique pour les concepts difficiles (asymétries, coûts transaction)
4. **Questions d'examens** : 2 années (2023, 2024) pour identifier questions récurrentes
5. **Approfondissements** : Banque supplémentaire couvre enjeux contemporains (numérique, IA, crises)

### **Spécificités de la Matière**
- **Multidisciplinaire** : Économie, droit, comptabilité, statistiques
- **Forte composante institutionnelle** : Compréhension organisations internationales essentielle
- **Concepts abstraits** : Asymétries information, coûts transaction nécessitent exemples concrets
- **Actualité économique** : IPC, inflation, normes IFRS → questions sensibles aux événements récents

### **Lacunes Potentielles**
1. **Peu de questions quantitatives** : Essentiellement QCM conceptuels, peu de calculs (sauf IPC)
2. **Institutions européennes** : Couverture limitée (BCE, Pacte Stabilité) vs importance réelle
3. **Cas pratiques** : Peu d'études de cas détaillées (Boeing-Airbus, guerre commerciale USA-Chine, etc.)
4. **Dimension historique** : Évolution institutions post-2020 (COVID, inflation 2022-2023) à actualiser

### **Suggestions d'Amélioration**
1. **Ajouter cas concrets récents** :
   - Sanctions OMC (Airbus-Boeing, acier-aluminium)
   - Programmes FMI (Argentine, Pakistan, Ukraine)
   - Réformes BM post-pandémie

2. **Renforcer dimension quantitative** :
   - Calculs IPC détaillés (effet substitution, qualité)
   - Ratios comptables IFRS vs normes françaises
   - Quotes-parts FMI (calcul droits de vote)

3. **Compléter institutions européennes** :
   - Mécanisme Européen de Stabilité (MES)
   - Banque Européenne d'Investissement (BEI)
   - Politique agricole commune (PAC)

4. **Actualiser enjeux contemporains** :
   - Inflation post-COVID
   - Guerre Ukraine (sanctions économiques)
   - Transition écologique (taxonomie verte UE)
   - Régulation plateformes numériques (DSA, DMA)

### **Difficulté Estimée par Thème**
- **Facile** : Dates historiques, missions organisations, définitions basiques
- **Moyen** : Comparaisons (FMI vs BM), principes gouvernance, normes IFRS
- **Difficile** : Asymétries information (sélection adverse vs aléa moral), coûts transaction (Williamson), biens communs (Ostrom), IPC (biais substitution)
