## 🎯 Méthodologie

### Pour chaque chapitre/thème:
1. Lire section inventaire détaillé
2. Identifier hiérarchie (Sections → SubSections → Notions)
3. Créer IDs systématiques (M2-I-1a, S3-II-2b, etc.)
4. Descriptions concises (1-2 lignes max)
5. Tags essentiels uniquement
6. Relations (formules, auteurs, prérequis)
7. Estimation temps réaliste

### Optimisations:
- ❌ Pas de `questionCount: 0` (sera calculé dynamiquement)
- ❌ Pas de `keywords`, `examples` (verbeux)
- ✅ Descriptions formule-centric quand applicable
- ✅ Tags courts (max 3 par notion)
- ✅ Relations explicites (prérequis, notions liées)
