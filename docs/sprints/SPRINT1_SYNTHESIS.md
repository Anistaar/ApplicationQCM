## 📐 Formules & Concepts Clés

### MACRO - 44 Formules

**Consommation** :
- C = C0 + cY (fonction keynésienne)
- PMC = ΔC/ΔY, PME = ΔS/ΔY
- k = 1/(1-c) (multiplicateur)
- Cp = γ·Yp (Friedman)
- C = α·Y^L + β·A (Modigliani)

**Investissement** :
- It = v·ΔYt (accélérateur simple)
- VAN = -I + Σ(Rt-Ct)/(1+i)^t
- ΠI/A = P + (P-r)·E/A (effet levier)
- q de Tobin = Valeur boursière / Coût remplacement

**Modèle classique** :
- MPL = W/P (demande travail)
- P·Y = M·v (Fisher)
- Y = f(K, L) (fonction production)

**Modèle keynésien** :
- Y = C + I + G + (X-M)
- IS : Y = C(Y-T) + I(i) + G
- LM : M/P = L(Y, i)

### INSTIT - Indicateurs Institutionnels

- **DTS** (Droits de Tirage Spéciaux) : panier monnaies FMI
- **Quotes-parts** : quote FMI détermine droits vote et accès crédit
- **IPC** : Indice Prix Consommation
- **IFRS** : International Financial Reporting Standards
- **Clause NPF** : Nation la Plus Favorisée (OMC)

### STATS - 30+ Formules Statistiques

**Centrale** :
- x̄ = Σ(xi·ni)/N (moyenne arithmétique)
- G = ⁿ√∏xi (moyenne géométrique)
- H = n/Σ(1/xi) (moyenne harmonique)
- Me = valeur telle que 50% ≤ Me ≤ 50%
- Qk = valeur telle que 25k% ≤ Qk

**Dispersion** :
- σ² = Σ(xi - x̄)²·ni/N = E(X²) - [E(X)]² (König)
- σ = √σ²
- CV = σ/x̄ × 100
- IQR = Q3 - Q1

**Transformations** :
- Var(aX + b) = a²·Var(X)
- σ(aX + b) = |a|·σ(X)
- CV(aX) = CV(X) (invariant multiplication)
